
# React + Raw Node.js Integration

## Objective
To connect a React frontend with a Raw Node.js backend.

## Technologies Used
- React
- Node.js
- HTTP module
- REST API

## Features
- Node.js server runs on port 5000.
- API returns a JSON message.
- React fetches data using useEffect.
- useState stores and displays the message.
- CORS allows communication between frontend and backend.

## How to Run

1. Start the backend:
   node backend/server.js

2. Open another terminal:
   cd frontend

3. Start React:
   npm start

4. Open http://localhost:3000
